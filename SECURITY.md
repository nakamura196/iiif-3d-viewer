# Security Policy

## Supported versions

Only the latest version on the `main` branch (deployed at https://kasane.ldas.jp) receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues.

Use GitHub's private reporting instead: open the [Security tab](https://github.com/nakamura196/iiif-kasane/security) and click **Report a vulnerability**. If that is not possible, email nakamura.satoru@mail.u-tokyo.ac.jp.

Please include the affected URL or file, steps to reproduce, and the impact you expect. We will acknowledge your report within a week.
