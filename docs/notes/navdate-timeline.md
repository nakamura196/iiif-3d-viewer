# Collection を navDate で年代順に並べる（年表）

## 2026-10-14

Cookbook 0230（navDate）に対応した。ブランチ feat/navdate-timeline。

- Collection の項目（Manifest・入れ子の Collection）に書かれた navDate を読むようにした。
- navDate を持つ項目が 2 件以上あるとき、一覧の上に「コレクションの順／年代順」の切り替えを出す。
  既定は「コレクションの順」。並び順は公開者が決めたものなので、こちらから勝手に変えない。
- 「年代順」では、年ごとに見出しを付けて縦の年表にする。navDate の無い項目は最後の「日付なし」に入れる。
- 各カードに日付を出す（どちらの並べ方でも）。

### 決めたこと

- **1 月 1 日 0 時は「年」だけを表示する。** 0230 の値は `1986-01-01T00:00:00Z` で、意味は「1986 年」。
  「1986年1月1日」と出すと、実在しない精度を示してしまう。資料情報タブ（about.ts）は従来どおり日付まで出す。
- **並べる鍵は自前で作る。** navDate は xsd:dateTime なので、紀元前（`-0499-...`）や 5 桁の年がありうる。
  Date.parse はこれを読めない。先頭の年・月・日・時・分・秒を数値にして並べる。タイムゾーンは無視した。
- 年 0 は天文年として扱い、紀元前 1 年と表示する（xsd 1.1 と同じ）。

### 却下した案

- **各 Manifest を取りに行って、Manifest 本体の navDate を読む。** 項目が数百ある Collection では
  要求が数百になる。0230 も Collection の項目側に navDate を書いているので、まずは項目側だけにした。
- **横向きの、年の幅に比例した年表。** 年が飛び飛び（例: 1600 年と 1990 年）だと、ほとんどが空白になる。
  縦の一覧で年を見出しにするほうが、件数が増えても読める。

### 確かめたこと

- vitest 440 件（chronology.test.ts を追加）、tsc、eslint が通る。
- E2E 7 件（0230 の年表を 1 件追加）が手元の開発サーバで通る。

### 未対応

- 年表の表示を URL に残す（`?order=date` のような引数）。
- 項目側に navDate が無く、Manifest 本体にだけある Collection。
- 0318（navPlace と navDate）の地図タブとの連動（年で地図の点を絞るなど）。

### 年表の幅を変えた（同日、ユーザーの指摘から）

最初の版は、年表でも一覧と同じ幅 11rem のカードを使っていた。0230 は各年 1 件なので、
左端に細いカードが縦に並び、右が大きく空いた。

- 「フッターと同じ幅に」を試した（Tailwind の container、1280px 幅の画面で最大 1280px、1920px で 1536px）。
  ビューアの左側の領域は右パネルの分だけ狭い（1920px の画面で約 1340px）。もともとこの上限より狭いので、
  見た目は変わらなかった。資料を開いている間のビューアにはフッターも出ないので、この案はやめた。
- 代わりに、年代順のときだけカードを横長の 1 行にした（左にサムネイル、右に題名・年・種類）。
  年表は中央の 1 列にまとめ、幅の上限は文章ページと同じ max-w-3xl にした。
  年表は上から読むものなので、読みやすい幅の縦の列のほうが合う。
- 「並べ方」の切り替えは左上から動かさない。押したボタンが、並べ方を変えた拍子に動かないようにするため。
- 1280px と 1920px の画面で見た目を確かめた。E2E 7 件が通る。

### サムネイルを Manifest から取る（同日、ユーザーの指摘から）

0230 の Collection は、項目にサムネイルを書いていない（Collection 全体に 1 枚あるだけ）。
そのため、どちらの並べ方でもカードに絵が出なかった。

- 項目にサムネイルが無いときだけ、その Manifest を取りに行く。最初に却下した「各 Manifest を取りに行く」を、
  **カードが画面に入ったときだけ**取る形にして採った。数百件の Collection でも、要求は見えている分だけで済む。
- 選ぶ順は、Manifest の thumbnail → 最初の Canvas の thumbnail → 最初の Canvas の画像。
  画像に Image API があれば `/full/,192/0/default.jpg` に縮める（0230 は ImageService3）。
  Choice は最初の選択肢を使う。Presentation 2 は読み込み時に 3 へ直るので、3 の形だけ見ればよい。
- 取った結果はページを開いている間だけ覚えておく。並べ方を切り替えても取り直さない。
- 絵が届くまでは同じ大きさの空きを置き、カードの高さが後から変わらないようにした。
- vitest 447 件、tsc、eslint、E2E（0230 でサムネイル 2 枚を確かめる行を追加）が通る。
  1280px の画面で、一覧と年表の両方に地図の絵が出ることを確かめた。
