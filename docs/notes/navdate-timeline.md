# Collection を navDate で年代順に並べる（年表）

## 2026-10-14

Cookbook 0230（navDate）に対応した。ブランチ feat/navdate-timeline。

- Collection の項目（Manifest・入れ子の Collection）に書かれた navDate を読むようにした。
- navDate を持つ項目が 2 件以上あるとき、一覧の上に「コレクションの順／年代順」の切り替えを出す。
  既定は「コレクションの順」。並び順は公開者が決めたものなので、こちらから勝手に変えない。
- 「年代順」では、年ごとに見出しを付けて縦の年表にする。navDate の無い項目は最後の「日付なし」に入れる。
- 各カードに日付を出す（どちらの並べ方でも）。

### 決めたこと

- **1 月 1 日 0 時は「年」だけを表示する。** 0230 の値は `1986-01-01T00:00:00Z` で、意味は「1986 年」。
  「1986年1月1日」と出すと、実在しない精度を示してしまう。資料情報タブ（about.ts）は従来どおり日付まで出す。
- **並べる鍵は自前で作る。** navDate は xsd:dateTime なので、紀元前（`-0499-...`）や 5 桁の年がありうる。
  Date.parse はこれを読めない。先頭の年・月・日・時・分・秒を数値にして並べる。タイムゾーンは無視した。
- 年 0 は天文年として扱い、紀元前 1 年と表示する（xsd 1.1 と同じ）。

### 却下した案

- **各 Manifest を取りに行って、Manifest 本体の navDate を読む。** 項目が数百ある Collection では
  要求が数百になる。0230 も Collection の項目側に navDate を書いているので、まずは項目側だけにした。
- **横向きの、年の幅に比例した年表。** 年が飛び飛び（例: 1600 年と 1990 年）だと、ほとんどが空白になる。
  縦の一覧で年を見出しにするほうが、件数が増えても読める。

### 確かめたこと

- vitest 440 件（chronology.test.ts を追加）、tsc、eslint が通る。
- E2E 7 件（0230 の年表を 1 件追加）が手元の開発サーバで通る。

### 未対応

- 年表の表示を URL に残す（`?order=date` のような引数）。
- 項目側に navDate が無く、Manifest 本体にだけある Collection。
- 0318（navPlace と navDate）の地図タブとの連動（年で地図の点を絞るなど）。
