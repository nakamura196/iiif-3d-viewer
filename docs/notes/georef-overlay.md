# ジオリファレンスの画像を地図に重ねる（/georef）

## 2026-10-14

### 何をしたか

`/georef` で、地点の付いた画像（絵図・古地図）を地図の上に重ねるようにした。
PR #62 で画像の上に対応点を出すところまでは済んでいた。その続き。

- 計算: `core/georefOverlay.ts`。対応点（画像の x, y と経度・緯度）から、
  1 次の多項式（アフィン変換）を最小二乗で求め、画像の四隅の経度・緯度を返す
- 表示: `src/components/map/MapView.tsx`。maplibre-gl の image ソースに四隅を渡して貼る。
  地図の左下に「画像を重ねる」のチェックと、濃さのつまみ（既定 0.7）
- 画像は Image API から長辺 4096 px で取る（`GeoRefContent.tsx` の `overlayUrlOf`）。
  元の画像は 18415 × 12911 px あり、そのままでは重く、WebGL のテクスチャの上限も超える

### 当てはめを Web Mercator で行う理由

地図ライブラリは、四隅の間を Web Mercator の平面で線形に埋めて描く。
そこで当てはめも同じ平面で行った。こうすると、求めた変換と画面に描かれる画像が一致する。
経度・緯度のまま当てはめると、緯度方向にわずかにずれる（狭い範囲なら実害は小さい）。

### 実測

geo.ldas.jp/manifest.json（帝国大学の構内鳥瞰図、対応点 27 点、`polynomial` の `order: 1`）で、
求めた変換で対応点を写し、指定の経度・緯度との差を地表の距離で測った。

- 中央値 7.8 m、最大 19.2 m、二乗平均 9.4 m（図の範囲は 2 km 四方ほど）
- 目で見ても、本郷通りが敷地の西の端に沿い、三四郎池の上に池の地点が乗る

### 試してやめた案

- Allmaps（`@allmaps/maplibre`）: 画像をタイルで取り、高次の変換や薄板スプラインにも対応する。
  ただし依存がまとまって増える。今回の見本は 1 次で足りるので、まず自前で 40 行ほどにした。
  高い解像度で見たい、または高次の変換を持つ Manifest が出てきたら、改めて検討する

### 扱っていないこと（限界）

- `transformation` は読んでいない。高次（`order: 2, 3`）や `thinPlateSpline` の Manifest も 1 次で近似する
- Canvas に画像が 1 枚だけ全面に貼られた場合に限る。一部に貼った画像・切り出し・回転・反転のときは重ねない
- 重ねる画像は長辺 4096 px まで。地図を寄せると元の画像より粗い
- 3D の Scene に地点が付いた Manifest では、何も変わらない（重ねる画像が無い）
- 確かめたのは Chrome（ja / en、明暗の切り替え）。Safari・Firefox・スマートフォンは未確認
