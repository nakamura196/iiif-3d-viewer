# 地図パネル（Cookbook 0139・0154・0240・0318）

## 2026-10-13

### 何をしたか

右パネルに「地図」タブを足した。場所の書いてある資料のときだけ出る。
これまでは「資料情報」タブに座標の文字と OpenStreetMap へのリンクを出すだけだった。

- 読み取り: `core/features/places.ts`。Manifest・Canvas・Range の navPlace、
  Collection の items の navPlace、GeoJSON の Feature を本文に持つ tagging 注釈を、1 つの一覧にする
- 表示: `react/panels/MapPanel.tsx`。今のページの場所は赤、ほかは青。
  一覧か地図の図形を押すと、そのページへ移る（Collection の項目なら、その Manifest を開く）

### 地図の部品を使わなかった理由

サイトには maplibre-gl（`src/components/map/MapView.tsx`）があるが、パッケージには入れなかった。

- パッケージ `@nakamura196/iiif-viewer` の依存は `@iiif/parser` だけ。maplibre は 1 MB 近く、
  さらにワーカーのファイルを公開フォルダへ写す手順が要る（サイトは `scripts/copy-maplibre-worker.mjs` で対応している）。
  パッケージを使う人に同じ手順を求めることになる
- 場所を示すだけなら、OpenStreetMap のタイル画像を並べ、上に SVG で点・線・多角形を描けば足りる。
  Web メルカトルの計算は 100 行ほどで、テストで確かめられる
- 却下した案: 地図の部品を外から差し込む口を作る（サイトの MapView を渡す）。
  使う人が部品を用意しないと地図が出ず、レシピの対応としては半端になる

### 実測・確認（ブラウザ、dev サーバ）

- 0240: 2 か所（ロサンゼルス・ワシントン）が両方収まる。2 つ目を押すとページ 2 に移る
- 0139: ポトマック川沿いの多角形が出る。一覧に範囲 `xywh=920,3600,1510,3000` を出す
- 0318（collection.json）: ローマの 5 か所。点を押すと、その Manifest が開き、画像も出る
- 0154 はテストのみ（ブラウザでは見ていない）

### 途中で分かったこと

- 変換後（convertToV4）の Collection は、items が空の Scene になるが、navPlace と navDate は残る。
  そのため地図タブは Collection を取り直さずに済む
- 地図の初期位置を「最初に幅が分かった時点」で決めると、パネルの幅が確定する前の値で決まり、
  片方の点が外れた。手で動かすまでは、幅が変わるたびに計算し直す形にした
- 拡大ボタンの下に点が隠れることがあったので、余白を 40 px にした
- `fitView` という名前が 3D 表示（viewCamera）に既にあり、`fitMapView` にした

### 確かめていないこと

- 0139 の範囲を、画像の上で強調すること（地図と画像の連動）。今は文字で出すだけ
- タイルの利用条件: tile.openstreetmap.org は軽い利用を前提にしている。利用が増えたら別のタイルを検討する
- `?tab=map` を URL で付けても最初に地図タブが開かない（サイト側の扱い。ほかのタブと同じか未確認）
